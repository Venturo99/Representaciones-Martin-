## ⚠️ Notas Importantes

1. **Verificación de Seguridad (Captcha):** El formulario incluye un código Captcha de 5 dígitos (en color naranja). Debes copiarlo tal cual (no distingue entre mayúsculas y minúsculas) para poder ingresar. Si te equivocas, puedes hacer clic en el botón de refrescar (🔄) para generar uno nuevo.
2. **Validaciones:** Asegúrate de escribir correctamente el correo (con formato válido) y la contraseña (mínimo 6 caracteres).
3. **Roles:** Cada usuario tiene acceso a módulos específicos dentro del sistema según su rol (esto se puede ver reflejado en el menú lateral y en las acciones permitidas).

> **Nota de desarrollo:** Este proyecto actualmente funciona como un *Frontend* puro (HTML, CSS, JavaScript) con una base de datos simulada. Al recargar la página, los datos volverán a su estado inicial.
